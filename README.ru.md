# Legion Thermals

[English](README.md) · [Скачать последнюю версию](https://github.com/knvnano/legion-thermals/releases/latest)

Монитор температур CPU/GPU с небольшим баннером поверх окон, одним значком трея и управлением вентиляторами поддерживаемых Lenovo Legion. C# / Avalonia / Windows10–11 x64.

## Установка

В [релизах](https://github.com/knvnano/legion-thermals/releases/latest) доступны установщик EXE и portable ZIP, оба со встроенным.NET. Распакуйте portable полностью. Программа сразу запрашивает права администратора; файлы не подписаны цифровым сертификатом. Контрольные суммы — SHA256SUMS.txt.

Перед обновлением завершите прежнюю копию через трей → Выход. Настройки сохраняются. После установки один раз запустите новую копию, чтобы обновился путь уже включённой задачи автозапуска.

## Возможности

- Перемещаемый полупрозрачный баннер поверх окон, выбор угла и непрозрачности.
- Один значок трея: CPU голубым сверху, GPU оранжевым снизу. Правый клик открывает меню.
- Ручной минимум скорости и таблица «температура → процент»30–100% с шагом10%.
- До16 строк, отдельная галочка планировщика, опрос каждые2сек по большей температуре CPU/GPU, гистерезис снижения3°C.
- Русский/английский язык переключаются кнопкой вверху настроек без перезапуска.
- Автосохранение, атомарная запись и резервная копия настроек.
- Повышенный автозапуск через планировщик Windows: без сохранения пароля и повторного UAC при входе, для текущего пользователя-администратора, через10сек после входа.

## Совместимость и охлаждение

Физически проверен Lenovo83DF / Legion Pro5 16IRX9 / BIOS N0CN32WW. Запись вентиляторов ограничена этой моделью и семейством BIOS N0CN; другие версии прошивки отдельно не проверены. Название Y9000 само по себе не гарантирует совместимость. [Подробнее](docs/HARDWARE.md).

Проценты — нижняя граница кривой, а не ограничитель охлаждения. Ручное/табличное управление включает Lenovo Custom, который также меняет режим производительности. При CPU≥90°C или GPU≥80°C программа просит максимальную кривую. При потере датчиков возвращается автоматика. При внешнем переключении режима управление приложения отключается.

Кнопка Auto и обычный выход восстанавливают исходные режим, кривую и флаг принудительных100%. После аварийного завершения журнал восстанавливается на следующем повышенном запуске; немедленный откат при принудительном завершении невозможен.

Настройки хранятся в `%LOCALAPPDATA%\LegionThermals\settings.json`, резервная копия — `.bak`. Автозапуск создаёт только собственную задачу `LegionThermals-<SID>` после включения пользователем. Программа не ставит сторонние драйверы/службы и не отправляет телеметрию.

## Исходники и сборка

Подробные комментарии на русском находятся непосредственно в C#-файлах. [Карта архитектуры](docs/ARCHITECTURE.md) объясняет слои и потоки.

```powershell
dotnet build LegionThermals/LegionThermals.csproj -c Release
dotnet run --project LegionThermals.Tests -c Release
```

Нужен.NET10 SDK. Установщик собирается штатным скриптом через NSIS3; см. [English README](README.md#build-from-source).

Диагностика `--diagnose` локальная. Перед публикацией сообщений/дампов в Issues удаляйте личные данные. Программа распространяется под [MIT](LICENSE): разрешены изучение, изменение и распространение при сохранении лицензии. Это независимый проект, не продукт Lenovo.
