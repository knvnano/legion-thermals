LEGION THERMALS1.2 — УСТАНОВКА И ЗАПУСК

Windows10/11 x64. В установщик включён.NET10; отдельная установка.NET не требуется.

1. Завершите прежнюю копию через трей → Выход, затем запустите установщик.
2. Ярлык открывает программу с запросом прав администратора сразу при запуске.
3. Включите «Автозапуск от администратора при входе в Windows»: приложение создаст задачу Windows с наивысшими правами, без сохранения пароля. При следующих входах запуск произойдёт через10сек без UAC. Отключение галочки удаляет задачу.
4. В настройках задайте таблицу температур и скоростей30–100% с шагом10%, затем включите планировщик вентиляторов. Он использует большую из температур CPU/GPU и проверяет её каждые2сек. Текущие обороты показаны отдельно от табличного целевого минимума.
5. Баннер можно перемещать, менять прозрачность, включать цифровой значок в трее. Настройки и таблица сохраняются автоматически.

Авто Lenovo и обычный выход восстанавливают исходные параметры охлаждения. Табличный процент задаёт минимум, не ограничивая охлаждение при нагреве. CPU≥90°C/GPU≥80°C включает максимальную кривую. Снижение по таблице имеет гистерезис3°C. При потере температур возвращается автоматика.

После установки и первого запуска путь уже включённого автозапуска обновится на установленную копию. Не перемещайте portable-папку без запуска новой копии, чтобы обновить путь задачи. Программа не создаёт сторонних служб или драйверов.

Удаление сохраняет пользовательские настройки и посторонние файлы. Задача текущего пользователя удаляется только если направлена на удаляемую программу. Задачи других учётных записей не изменяются.
